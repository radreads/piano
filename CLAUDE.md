# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

This is a **personal context repository** for piano and music learning, not a traditional software development project. It contains contextual information for LLMs assisting with music theory, piano practice, and music production.

## Key Context File

**[readme.md](readme.md)** - Complete context pack containing:
- Personal background and learning style
- Current piano skills and equipment (Yamaha P-45)
- Musical goals (6-12 month horizon)
- Practice philosophy and mental models
- Progress tracking (starting from Week 1)

## How to Use This Repository

When assisting in this directory:

1. **Always read [readme.md](readme.md) first** to understand:
   - Who you're helping (Khe - analytical, first-principles thinker)
   - Current skill level (beginner bass clef, intermediate treble clef)
   - Musical taste (progressive house, Einaudi, Bicep, Fred again..)
   - Practice constraints (~4-5 hours/week)

2. **Align with the practice philosophy** (Section 6 in readme.md):
   - Three Operating Systems (Physical, Rhythmic, Harmonic)
   - Shapes first, names second
   - Numbers/functions over letters (Roman numerals)
   - Tiny loops, not whole songs
   - Constrained sandbox (C major, A minor focus)

3. **Response style preferences**:
   - Direct, concise, no fluff
   - Structured with checklists and frameworks
   - Tie piano work back to electronic music production
   - Concrete drills, not vague advice

4. **Integration with music production**:
   - Always consider how piano skills translate to DAW work
   - Frame harmony/melody through the lens of electronic music production
   - Reference progressive house, techno, and atmospheric music contexts

## Common Use Cases

This directory may be used for:
- Practice session planning
- Music theory explanations tailored to production
- Repertoire suggestions (Einaudi-style pieces)
- Progression analysis for electronic music
- Practice logs and progress tracking
